# 🎂 B-DAY — Личный сайт-открытка к дню рождения

Тёплый одностраничный сайт с PIN-кодом, музыкальным плеером и письмом.

## 🚀 Как запустить

Просто открой файл **`index.html`** в любом браузере (Chrome, Firefox, Edge).
Сборка и сервер не нужны — всё работает на чистых HTML/CSS/JS.

---

## 🔑 PIN-код по умолчанию: `2026`

Чтобы изменить код:

1. Открой файл **`js/main.js`**
2. Найди в самом верху строку:
   ```js
   const SECRET_PIN = "2026"; // ← СМЕНИ на свой секретный код!
   ```
3. Замени `"2026"` на любой 4-значный код (например, дату рождения)

---

## 🎵 Как добавить свою музыку

1. Создай папку **`assets/audio/`** внутри проекта (уже создана)
2. Положи туда свой трек в формате **.mp3** с именем:
   ```
   assets/audio/birthday-song.mp3
   ```
3. Готово! Плеер на сайте сразу подхватит твой трек.

> ⚠️ Если файла нет — кнопка play не будет работать, но сайт откроется нормально.
> Также можно изменить путь к треку в `js/main.js` (массив `MUSIC_SOURCES`).

### Кнопка плеера

В левом нижнем углу есть круглая кнопка с нотой:

- на компьютере плеер открыт сразу, кнопка его сворачивает и разворачивает;
- на телефоне плеер по умолчанию спрятан — кнопка открывает компактную карточку внизу экрана;
- пока играет музыка и карточка закрыта, нота на кнопке мягко покачивается;
- закрыть карточку на телефоне можно также клавишей **Esc**;
- музыка при закрытии карточки не останавливается.

## 📸 Фотографии в галерее

Фото уже вставлены в главы **«Chapters from our story»** и лежат в папке **`assets/photos/`**:

| Глава | Файл | Что на фото |
|-------|------|-------------|
| Chapter One   | `photo1-sakura.jpg`    | под цветущей сакурой |
| Chapter Two   | `photo2-candles.jpg`   | вечер при свечах |
| Chapter Three | `photo3-mirror.jpg`    | отражение в зеркале |
| Chapter Four  | `photo4-clown.jpg`     | клоунский макияж |
| Chapter Five  | `photo5-spiderman.jpg` | маска Человека-паука |
| Chapter Six   | `photo6-swing.jpg`     | осенние качели |

Чтобы заменить фото, просто положи новый файл в `assets/photos/` и поменяй путь в `index.html`:

```html
<div class="story-image-container">
    <img src="assets/photos/photo1-sakura.jpg" alt="Chapter One — наше начало" loading="lazy" />
    <span class="story-image-hint" aria-hidden="true">Добавь фото</span>
</div>
```

Фото автоматически заполняет контейнер (`object-fit: cover`), получает скруглённые углы и неоновое свечение. Если `src` пустой или файл не найден — показывается подсказка «Добавь фото».

### 🎵 Обложка плеера

Чёрно-белая версия фото лежит в **`assets/photos/music-player.jpg`** и подставляется как обложка плеера через CSS:

```css
.album-art .album-inner {
  background-image: url("../assets/photos/music-player.jpg");
}
```

Чтобы поменять обложку — замени этот файл (лучше вертикальное фото) или укажи новый путь в `css/style.css`.

## 🕯️ Свеча и микрофон

В конце страницы есть блок **«Make a wish»**:

- кнопка **«Включить микрофон»** — попросит доступ к микрофону и будет ждать, пока ты подуешь в него;
- чувствительность настроена на лёгкий выдох: достаточно короткого «пуфа» на 0,1–0,2 секунды;
- когда поток воздуха достаточно сильный, свеча гаснет, появляется дым и искры;
- кнопка **«Задуть вручную»** — резервный вариант, если микрофон недоступен;
- после этого свечу можно зажечь снова.

> 💡 Для микрофона браузеры требуют безопасный контекст. Если кнопка не срабатывает при открытии файла напрямую, запусти сайт через локальный сервер:
> ```
> python -m http.server 8000
> ```
> и открой `http://localhost:8000`.

## ✉️ Как отредактировать письмо и тексты моментов

В `index.html`:
- Секция **«Наши мгновения»** — 6 карточек с заголовками `<h3>` и текстом `<p class="moment-text">`. Замени на свои воспоминания.
- Секция **«Письмо для тебя»** — абзацы в `.letter-body`. Напиши своё письмо 💌

## 🌐 Публикация на GitHub Pages

Сайт публикуется автоматически при каждом пуше в ветку **`main`**.

- Workflow: `.github/workflows/deploy.yml`
- Адрес сайта: **https://oserpuy.github.io/happy-/**
- Репозиторий: **https://github.com/oserpuy/happy-**

### Как это работает

1. Ты пушишь изменения в `main`.
2. GitHub Actions собирает сайт (workflow **Deploy to GitHub Pages**).
3. Сайт обновляется на GitHub Pages через несколько минут.

### Что сделать один раз

В настройках репозитория: **Settings → Pages → Build and deployment → Source** = **GitHub Actions**.
Workflow делает это сам при первом запуске, но если Pages выключен — выбери этот пункт вручную.

> ⚠️ Сайт опубликован публично. PIN-код (`2026`) — единственная защита, и он виден в исходниках `js/main.js`.
> Не храни на сайте ничего по-настоящему секретного: любой, кто откроет исходники, сможет найти код.
